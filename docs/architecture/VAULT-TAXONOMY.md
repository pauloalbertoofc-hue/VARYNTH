# Vault Taxonomy Integration

O Vault continua sendo o repositório de arquivos e metadados do usuário. `knowledgeFromVaultItem` produz um KnowledgeItem derivado sem alterar a organização física nem apagar a classificação legada.

A classificação semântica pode apontar para múltiplos domínios. A origem permanece `VAULT_ITEM`, com referência ao item, data e autoridade do usuário. O usuário mantém controle sobre correções e publicação entre agentes.
