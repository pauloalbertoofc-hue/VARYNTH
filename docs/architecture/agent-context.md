# Agent Context

O `AgentContextAssembler` combina packs compactos de conhecimento e experiência com orçamento explícito. Knowledge, Experience, Preference, Memory e Policy permanecem entidades distintas.

O contexto é montado sob demanda por tarefa, domínio, projeto, agente e módulo. A instrução atual não é substituída por preferência inferida, e o sistema não inclui o Vault inteiro automaticamente.
